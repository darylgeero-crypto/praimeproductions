Master a song — live = export

Same chain as the Zero-Latency page: high-pass 30 Hz, low shelf 200 Hz, peak 3000 Hz, high shelf 10000 Hz, compressor, saturation, limiter −1 dB. One chain function for live and for offline render.

If the picker does not open in a preview, download this file and open it in Chrome.

Raw song level before input gain — the bar moves only while Play live is playing. If it stays pinned at full, the raw song is hot: lower the input gain or run Auto-master. Output level is the mastered signal after EQ, compressor, saturation and limiter — compare it with the input bar to see what the chain is doing.

Values shown are the slider settings — a genre curve adjusts them at Play / Render.

Genre curve is honest: it applies a documented per-family curve (see code: masterGenreCurve), NOT a proven per-genre multiband engine — the original Master 22 curve was display-only. Trap/Drill: tighter compression + more high shelf. Lo-Fi: softer compression + rolled-off highs. Boom Bap: warm low shelf. Choosing a genre adjusts the EQ/compressor/drive above; "None" uses your sliders exactly.

Keyboard shortcuts: Space = Play / Stop · M = Bypass on/off · R = Render & download WAV. Shortcuts are ignored while you are typing in a field.
