Full-Length Beat Studio

1. Prompt — this drives everything

Type it like you would say it: genre, mood, tempo, structure, anything. The beat is varied by genre × tempo × beat structure × prompt × every option below — change any one of them and you get a different beat, with a different fingerprint. Same prompt + same options = same fingerprint, so you can rebuild it exactly.

2. Humanize — played, not stamped out

From Full 12's HumanizeEngine: swing on off-beats, timing jitter, velocity jitter scaled by section (Hook louder, Outro gentler), fills on the last bar of a section, and call-and-response melody — Verse second half answers a degree up, Bridge answers a degree down, Hook motif never touched so it stays recognisable.

3. Render full-length beat

Step Editor + Timeline — restored

Restored from Full 12: a 16-step editor, a section timeline, and project save/load. Honest wiring: this grid drives the card-3 Render (the page's own offline render) when "Use step pattern in Render" is checked — what you toggle is what you hear in that render. The separate SuperBeat generator below takes a prompt only and does not read this grid.

Grid: toggle steps on/off. Steps 1, 5, 9, 13 are the beats of the bar. Row M (mute) silences that row in Preview only — Render uses the full pattern. Copy pattern copies the grid as text (x = on, . = off), one line per row. Paste pattern reads that same 4-line text back into the grid. Mirror reverses the step order in every row. Swap rows exchanges two rows' 16-step patterns.

Timeline — sections

These sections are what card-3 Render uses (instead of the structure select) once you edit them. Changing the structure select resets this timeline to that structure.

Project — save / load (this browser only)

Saved projects live in this browser's localStorage only — they are not sent anywhere and are not on the server.

4. Lyrics for this beat — never the same twice

Generated from your prompt theme, not fixed templates. Full 12's lyric pad was honest about this: it served the same fixed lines every time for only 3 genres. This one does not. It combines a large English vocabulary (adjectives, nouns, verbs, places, rhyme families) with your prompt, seeded by the same fingerprint, and checks every generation against your history — if an exact lyric was already generated, the seed bumps automatically and it regenerates.

Honest dictionary note: this page does not embed the entire 170,000-word English dictionary — that would be megabytes of obscure and archaic words, and random dictionary words break rhyme and flow. It uses a large curated English vocabulary (hundreds of words across rhyme families, plus your prompt words) combined combinatorially, so the number of possible lyrics is in the billions, and the history check guarantees no exact repeat in your generations.
