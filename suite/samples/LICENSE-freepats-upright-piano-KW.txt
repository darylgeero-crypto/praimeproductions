AUTHENTICITY — a real acoustic Kawai upright piano, not a runtime oscillator
- The source is a multi-sampled recording of a real Kawai upright
  piano in a living room (Zoom H1 stereo recording, Jan 2017) —
  captured as audio files, NOT a Web Audio oscillator generated at
  runtime in the app. The bank is labelled "Upright Piano" honestly;
  it is not presented as a concert grand. This is a DIFFERENT piano
  from the VSCO piano (60 notes), the old piano FB (78 notes,
  honky-tonk Francis Bacon player piano, stereo Zoom H1n), and the FM
  pianos (DX7 patches via Hexter): a warm living-room upright, so it
  is a separate bank, not a duplicate.
- All 66 source FLACs are 44.1 kHz STEREO (Zoom H1); durations
  0.69-10.47 s (low notes ring longest, top notes decay in under a
  second). The bank downmixes to mono (ffmpeg -ac 1), same as the
  old-piano bank.
- Pitch probe (measure_uprightkw.py + per-harmonic cross-check):
  every fundamental sits within -5.8..+8.3 cents of its keycenter
  (mean -0.6) — the piano is in tune at A440, so NO pitch correction
  was applied (SFZ has no tune= opcodes). The 0.5 s harmonic-sum
  scorer read -60..+34 cents at the range extremes; those are scorer
  artefacts, cross-checked per-harmonic (B0 fundamental -4.6 cents,
  A0 +8.3, C8 -0.0). Sources peak at -0.08..-4.16 dBFS (mono
  downmix).

VERIFICATION (verify_uprightkw.py, 2026-11-12)
- ALL 36 files PASS: every built note matches its SOURCE pitch within
  0.0-2.7 cents (built-vs-source difference, measured from the 2nd
  harmonic — see pitch-measurement notes below); built peak levels
  -18.19 to -19.09 dB (target -18.5 +/- 1 dB); all decode as vorbis
  OGG, 44.1 kHz mono. Built durations 0.69-10.47 s.
- Kits OGG count: 1724 -> 1760.
- PITCH-MEASUREMENT NOTES (record for future runs): the 0.5 s
  harmonic-sum scorer is unreliable at this bank's range extremes
  (read -60..+34 cents on sources whose fundamentals are within
  -5.8..+8.3 cents). The fundamental peak alone is also unstable
  below ~40 Hz: the four lowest notes (27-38 Hz) first failed with
  sign-flipped ~10-19 cent h1 diffs, while a fixed-window cross-check
  proved the built files are the same audio (waveform residual
  0.047-0.064 = Vorbis q5 noise, lag 0 samples) and the h2 readings
  agree to -0.5/+0.0/+0.0/+2.3 cents. One FFT bin is ~2.6 cents at
  27.5 Hz, so h1 peak-picking flips between adjacent bins on Vorbis
  noise; h2 sits at twice the frequency with twice the cent
  resolution and is stable. C1's h2 reading also wandered ~9 cents
  between a 0.05 s-start window (attack transient + string beating)
  and a 0.5 s-start window, so the verify uses a 0.5 s-start window.
  Lesson: for low notes, measure pitch from h2 with a settled window
  (0.5 s after onset), with parabolic interpolation, decoding the
  built OGG at the same 44.1 kHz as the source WAV.
